## ⚡ What is ValorX?

**ValorX** adalah AI skill untuk Claude Code yang mengubah cara kamu menganalisis, mengevaluasi, dan membangun produk.

**ValorX** is a Claude Code AI skill that transforms how you analyze, evaluate, and build products.

ValorX bukan chatbot generik. ValorX adalah **specialized intelligence system** yang:

- 🎯 **Memahami nilai konsumen** melalui Theory of Consumption Values (Sheth, Newman & Gross, 1991)
- 🧠 **Berpikir seperti product strategist senior** — bukan template mesin
- 🔬 **Evidence-driven** — semua klaim dilabeli jelas: fakta, riset, inferensi, atau hipotesis
- ⚡ **Langsung actionable** — setiap output ada langkah konkret berikutnya
- 🌐 **Bilingual** — berbicara Indonesia dan English secara natural

## 💡 Cara Menggunakan / How to Use

ValorX diaktifkan secara otomatis ketika kamu menyebut trigger keywords.

**Contoh prompt dalam Bahasa Indonesia:**

```
Analisis ide produk saya: aplikasi meal planning untuk ibu bekerja

---

Audit produk ini: [nama produk yang sudah ada]

---

Cari peluang inovasi di industri fintech untuk UMKM Indonesia

---

Kenapa konsumen mau beli produk saya? Analisis mendalam.

---

Validasi apakah ide ini worth building: marketplace untuk jasa fotografer
```

**Example prompts in English:**

```
Evaluate my product idea: a habit tracking app for remote workers

---

Audit this product: [existing product name or description]

---

Find unmet consumer needs in the B2B SaaS productivity space

---

Should I build this? A subscription box for specialty coffee enthusiasts

---

What's the value proposition for a budgeting app targeting Gen Z?
```

```
✅ G1: Theoretical Accuracy   — 5 dimensi TCV benar, Economic Value sebagai additional lens
✅ G2: Product Intelligence    — Mode operasi tepat dipilih
✅ G3: Consumer-Centricity     — Setiap rekomendasi terhubung ke consumer problem
✅ G4: Evidence Integrity      — Zero data fabrikasi
✅ G5: Analytical Depth        — WHY dijelaskan, bukan hanya WHAT
✅ G6: Actionability           — Next steps spesifik dan executable
✅ G7: Consistency             — Tidak ada kontradiksi antar framework

```

## 🚫 Anti-AI-Slop Guarantee

ValorX dirancang dengan prinsip **zero-tolerance terhadap AI slop**:

```diff
- Generic business jargon tanpa substansi
- Market statistics yang dikarang
- SWOT analysis dangkal sebagai pengganti consumer intelligence
- Framework name-dropping tanpa aplikasi nyata
- Skor yang di-inflate untuk terlihat meyakinkan
- Rekomendasi yang sama untuk semua produk
- "Lakukan riset lebih lanjut" sebagai jawaban akhir

+ Original analytical thinking berbasis consumer reality
+ Transparent evidence taxonomy dengan confidence scoring
+ Insight yang spesifik, bukan platitude generik
+ Rekomendasi yang berani dengan justifikasi yang jelas
+ Ketidakpastian yang diakui dengan honesty
+ Actionable roadmap yang bisa dieksekusi besok pagi
```

## 📈 Recommendation Framework

ValorX selalu berakhir dengan rekomendasi yang jelas — bukan "it depends":

| Rekomendasi | Kondisi |
|-------------|---------|
| ✅ **BUILD** | Strong evidence, clear consumer value |
| ⚠️ **BUILD WITH CONDITIONS** | Value exists, specific risks harus dimitigasi dulu |
| 🔬 **VALIDATE FURTHER** | Promising tapi evidence belum sufficient |
| 🔄 **REDESIGN** | Problem real, pendekatan solusi perlu rethink |
| 🔧 **IMPROVE** | Produk existing butuh targeted refinement |
| 📍 **REPOSITION** | Value ada, targeting atau framing yang salah |
| ❌ **DO NOT BUILD** | Market tidak cukup besar atau problem tidak material |
