# THEORY OF CONSUMPTION VALUES — REFERENCE

> Sheth, Newman & Gross (1991) — The authoritative framework for understanding
> why consumers choose one product over another.

---

## CORE PREMISE

Consumer choice is not driven by a single value.
Consumers simultaneously weigh **multiple independent value dimensions**.
A product that excels in one dimension but fails in others may still lose.
Understanding which dimensions matter most to your target segment is the strategic key.

---

## DIMENSION 01 — FUNCTIONAL VALUE ⚙️

**Definition:** Utility derived from the product's ability to perform its intended function.

**Core Question:** *Does the product actually work and deliver what consumers need?*

### What to Analyze

| Sub-dimension | Key Questions |
|--------------|---------------|
| Performance | Does it do what it claims to do, consistently? |
| Reliability | How often does it fail? What happens when it does? |
| Durability | How long does it last relative to expectations? |
| Features | Do features solve real problems or create noise? |
| Efficiency | How much effort/time does it save vs. alternatives? |
| Accuracy | How precise/correct are its outputs? |
| Convenience | How easy is it to access and use? |
| Usability | How steep is the learning curve? |
| Problem-solving | Does it resolve the core pain, or only symptoms? |

### Diagnostic Questions
- What is the product's primary function?
- How does it perform against the consumer's alternative (including "do nothing")?
- Where does functional performance break down?
- What is the gap between claimed and delivered performance?
- Which features are used vs. ignored vs. frustrating?

### Red Flags
- Performance that only works under ideal conditions
- Reliability issues that erode trust over time
- Features added for marketing, not for consumer jobs
- Convenience that only exists in demos, not real use

## DIMENSION 02 — SOCIAL VALUE 👥

**Definition:** Utility derived from the product's association with social groups, identity, and status.

**Core Question:** *What does using this product say about the consumer to themselves and others?*

### What to Analyze

| Sub-dimension | Key Questions |
|--------------|---------------|
| Status/Prestige | Does using this confer social status? |
| Belonging | Does this signal membership in a desired group? |
| Self-expression | Does this communicate the consumer's identity? |
| Group affiliation | Is there a community around this product? |
| Reputation | Does using this enhance social standing? |
| Social signaling | Is the product visible enough to signal values? |
| Peer influence | Do peers use, recommend, or avoid this product? |

### Diagnostic Questions
- Who else uses this product, and does that matter to consumers?
- Is the product visible or privately consumed?
- Does usage reinforce or conflict with consumer identity?
- Is there a community or tribe around this product category?
- How do consumers feel when seen using this product?

### Social Value Spectrum
```
LOW SOCIAL VALUE          ←————————→          HIGH SOCIAL VALUE
(Private, invisible,       (Public, identity-laden,
 commodity-like)            status-conferring)
```

Products on the left: Social value rarely drives choice.
Products on the right: Social value can dominate decision-making.

## DIMENSION 03 — EMOTIONAL VALUE ❤️

**Definition:** Utility derived from feelings and emotional states the product creates.

**Core Question:** *How does this product make the consumer feel, before, during, and after use?*

### What to Analyze

| Emotional State | Positive Form | Negative Prevention |
|----------------|--------------|---------------------|
| Confidence | "This makes me feel capable" | Reduces anxiety/doubt |
| Security | "I feel safe/protected" | Reduces fear/uncertainty |
| Happiness | "This brings me joy" | Reduces frustration/disappointment |
| Comfort | "This is soothing" | Reduces stress/discomfort |
| Fulfillment | "I feel accomplished" | Reduces feeling stuck |
| Trust | "I know this will work" | Reduces doubt/risk perception |
| Excitement | "I look forward to using this" | Reduces boredom |

### Diagnostic Questions
- What emotion does the consumer feel when they realize they need this product?
- What emotion does successful use create?
- What emotion does failure/friction create?
- Is there an emotional transformation (before → after) the product enables?
- Is the emotional value explicit in marketing or latent in usage?

### The Emotional Journey Map
```
TRIGGER → CONSIDERATION → PURCHASE → FIRST USE → REPEATED USE → ADVOCACY
 (fear?)    (hope/doubt)   (relief)   (surprise)   (satisfaction)  (pride)
```

Identify the dominant emotion at each stage. Design for the emotion, not just the function.

## DIMENSION 04 — EPISTEMIC VALUE 🔍

**Definition:** Utility derived from curiosity, novelty, learning, and intellectual stimulation.

**Core Question:** *Does this product give consumers a compelling reason to explore, discover, and return?*

### What to Analyze

| Sub-dimension | Key Questions |
|--------------|---------------|
| Novelty | Is this genuinely new or familiar-with-twist? |
| Curiosity | Does it make people want to explore further? |
| Discovery | Does using it reveal new possibilities? |
| Learning | Does the consumer become more capable over time? |
| Experimentation | Does it reward trying new things within it? |
| Intellectual satisfaction | Does mastery feel rewarding? |
| Innovation | Does it push the category forward? |

### Diagnostic Questions
- Is the initial experience surprising or expected?
- Does the product have depth that reveals over time?
- Is there a "progression" experience (beginner → intermediate → expert)?
- Does usage make consumers feel smarter, more capable, more creative?
- What happens to epistemic value at product maturity?

### Epistemic Value Decay Warning
Epistemic value is **the most volatile dimension**. Novelty fades. Curiosity is satisfied. Learning plateaus.
Products relying heavily on epistemic value must plan for:
- Continuous new content, features, or challenges
- Community-generated discovery
- Mastery systems that extend the learning arc

## DIMENSION 05 — CONDITIONAL VALUE 📍

**Definition:** Utility derived from specific situational or contextual circumstances.

**Core Question:** *Under what specific conditions does this product become dramatically more valuable?*

### What to Analyze

| Condition Type | Examples |
|---------------|---------|
| Temporal | Time of day, season, before deadlines, during commute |
| Spatial | At home, traveling, at work, in social settings |
| Occasion | Celebrations, emergencies, transitions, rituals |
| Life stage | Student, new parent, retirement, career change |
| Urgency | Time pressure, crisis, opportunity window |
| Environmental | Weather, cultural context, economic conditions |
| Social context | Alone, with family, with colleagues, public |

### Diagnostic Questions
- In what specific situations does this product's value spike dramatically?
- Are there situations where this product is useless or harmful?
- How does the product's value change across seasons, life stages, or contexts?
- What situational trigger leads to the purchase decision?
- Is conditional value the primary driver (situational product) or secondary?

### Conditional Value Map Template
```
PEAK VALUE MOMENTS:
  When: [time/situation]
  Who: [specific segment in that situation]
  Why: [which other values spike in context]
  
ZERO VALUE MOMENTS:
  When: [situation where product is irrelevant]
  Risk: [risk if product designed only for peak, not typical use]
```

## ECONOMIC VALUE LENS 💰

> ⚠️ NOT an original TCV dimension. An additional analytical lens.

**Definition:** The financial calculus consumers make when evaluating a product's worth.

**Core Question:** *Is the value delivered worth the full cost of obtaining and owning it?*

### What to Analyze

| Cost Type | Description |
|-----------|-------------|
| Price | Direct monetary cost |
| Time cost | Setup, learning, usage time |
| Switching cost | What it costs to leave current solution |
| Opportunity cost | What else could be bought with this budget |
| Total cost of ownership | Hidden costs over product lifetime |
| Risk cost | Financial risk of making wrong choice |

| Value Type | Description |
|-----------|-------------|
| Direct ROI | Measurable money saved or earned |
| Time ROI | Hours saved × value per hour |
| Risk mitigation value | Cost of problems avoided |
| Perceived value | What consumer believes it's worth |
| Price fairness | Whether price feels justified given alternatives |

### Willingness to Pay Analysis
```
MAXIMUM WTP: What would consumer pay if they had no alternatives?
CURRENT WTP: What consumer actually expects to pay?
WTP DRIVER: Which value dimension most justifies premium pricing?
WTP GAP: Gap between value delivered and price perception
```

---

## INTERACTION EFFECTS

Dimensions do not operate in isolation:

- **Functional ↔ Emotional:** Strong functional performance builds emotional trust
- **Social ↔ Emotional:** Social validation creates emotional security
- **Epistemic ↔ Functional:** Learning how to use increases functional effectiveness
- **Conditional ↔ All:** Situational context amplifies or mutes all other dimensions
- **Economic ↔ All:** High value in multiple dimensions justifies premium pricing

---

## COMPETITIVE VALUE POSITIONING

For each competitor, complete the Multi-Dimensional Analysis Matrix.
Then map on a 2D space using the two dimensions that matter most to target consumers.

This reveals:
- Where competitors cluster (crowded value space)
- Where value gaps exist (uncontested positioning)
- Which dimensions are table stakes vs. differentiators
- Where you can win with realistic resources
